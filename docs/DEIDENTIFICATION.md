# 去敏发布说明

此仓库从当前工作台源代码按允许清单导出，使用全新的 Git 历史，不包含原仓库的历史提交。

已排除原始业务 Excel/CSV/JSON、历史统计和产能报表、规范 PDF、原业务截图、构建日志、个人配置、临时文件及第三方缓存。只保留当前查询工作台及其构建、导入、配置、规则和测试代码。

内置演示数据是独立生成的虚构记录，未使用真实记录的替换、扰动或一一映射；数据集、gzip/base64 内容、内嵌 HTML 与示例 Excel 均来自同一个演示生成器。演示品牌、人员、部门、编码和条码不指向真实业务主体。

内网主机、共享目录和本机绝对路径已从默认配置中移除。共享访问需要用户在自己的环境显式配置，默认仅支持本地导入。个人配置使用本项目独立目录，避免复用其他本地工具的设置。

保留的字段、校验与路线计算用于展示功能，默认规则是示例，不代表企业当前生产口径。历史业务分析应用和报表不在此次发布范围内。

## 后续发布

1. 不提交生产导入文件、个人配置、业务截图或导出结果。
2. 执行 `python3 scripts/generate_demo.py` 恢复虚构演示集。
3. 执行 `python3 scripts/check_release.py` 检查 Excel、压缩数据与内嵌 HTML 一致、演示身份约定和发布文件类型。
4. 运行测试，检查 `git diff --cached` 后再推送。

`.gitignore` 只是辅助；导入操作会更新已跟踪的数据集和 HTML，因此每次发布前都需要检查。用户自己的内网地址和配置只应保存在本机环境中。
